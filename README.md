Thank you for checking out the Mega Man Zero 3 Poptracker! I hope that this tool helps even more people to feel confident and enjoy playing with the MMZ3 archipelago, whether you're an old hat with the MMZ series or just want to try something new!

Huge thanks to Stingrays110 for their work developing the randomizer. You can find the MMZ3 apworld at https://github.com/brodieberger/MMZero3Archipelago

You will also need to have downloaded Poptracker (https://poptracker.github.io/) and Archipelago (https://github.com/ArchipelagoMW/Archipelago) to use this tracker.

# Installation and Usage
- Download the .zip file from the GitHub Releases
- Move the downloaded .zip file into your PopTracker packs folder
- Launch PopTracker and select the MMZ3 Archipelago Tracker, choosing the variant you prefer (map recommended)
- To connect to an Archipelago host for auto-tracking, click on the AP button in the top bar and enter the host details

# Features
This tracker includes:
- Item tracking: including progressive weapons, EX Skills, armor chips, total disk counts, and stage access & progress
- Location tracking: full maps for every stage with logic-adhering location markers that will auto-clear when found in game, if synced to the AP server
- Settings to toggle itemsanity, 1upsanity, shop reminder, and map auto-switching
